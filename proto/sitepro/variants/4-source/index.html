Three packages that stack

Same markup. Three build steps.

  1. 01

    @luz-ds/tokens

    Design tokens as CSS custom properties, in three colour modes: light, dark and high contrast. 5 KB ceiling.

  2. 02

    @luz-ds/core

    Bare HTML elements styled with no class, layout objects and 29 components. Optional JS. 11.5 KB ceiling.

  3. 03

    @luz-ds/catalog

    41 site-wide pieces and page patterns for landing, blog, app and docs sites. One stylesheet each, no bundle.
