The design system made of light.

LUZ is Light, Usable and Zero-dependency: a design system in plain HTML, CSS and ES modules. Nothing to install at runtime. It still works with JavaScript off.

01 The split

One beam in. Three packages out.

LUZ comes in three layers that stack. Take the first, or all three, in order: tokens stand alone, core sits on tokens, catalog sits on both.

  • @luz-ds/tokens
  • @luz-ds/core
  • @luz-ds/catalog

02 @luz-ds/tokens

Every colour, size and step, as one variable.

Design tokens as CSS custom properties. Three colour modes out of the box: light, dark and high contrast. Change a token, and everything downstream follows.

03 @luz-ds/core

HTML that looks finished before you add a class.

Bare elements styled with no class. Layout objects for the page. Components for the rest, with JavaScript that is optional: it only enhances what the browser already does.

04 @luz-ds/catalog

Whole sites, one stylesheet at a time.

Site-wide pieces and page patterns for landing pages, blogs, apps and docs. One stylesheet each and no bundle: a page links only what it uses.
