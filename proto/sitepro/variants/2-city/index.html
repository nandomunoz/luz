v0.4.1 Beta · MIT · Zero dependencies

A design system you can build a city on.

LUZ is Light, Usable and Zero-dependency: a design system in plain HTML, CSS and ES modules. Three packages that stack, from the ground up.

Get started → Read the docs
npm create @luz-ds@0.4.1

Proposed setup command. Scroll to tour the city.

01 The ground

Tokens pave every street.

@luz-ds/tokens is the design language as CSS custom properties: colour, type, space and motion. Everything else stands on it.

Three colour modes ship in the box: light, dark and high contrast. Relight the city:

The paving is the real palette: one row per colour family, one tile per step, raised by its step.

02 The buildings

Write HTML. It already stands.

A <button>, a <table>, a <dialog>: @luz-ds/core styles bare elements with no class, then adds layout objects and components. JavaScript is optional and only enhances what the browser already does.

03 The skyline

Raise only the towers you need.

@luz-ds/catalog adds the pieces that act for a whole site and the page patterns of landing pages, blogs, apps and docs. One stylesheet each, no bundle: link what you use, after core.

04 Building code

A city with rules it never bends.

  • 0runtime dependencies. Nothing to audit but the platform.
