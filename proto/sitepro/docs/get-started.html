Get started · Tutorial

Set Luz up in one command

Run one command in your project. It looks first, asks only what it cannot tell, shows you the plan, and writes nothing until you say yes.

Package
@luz-ds/tokens, @luz-ds/core
JavaScript
Optional

Edit on GitHub

Luz is in beta.

Everything here works and is tested, but names can still change before 1.0. Pin an exact version and read the changelog before you upgrade.

Run the setup

In the folder of your project, new or not:

  1. It looks at your project

    Your stack (plain HTML, Astro, React, Vue or Angular), your package manager, the language of your pages, and whether Luz or another CSS framework is already there. What it finds becomes the default answer, never a final one.

  2. It asks what it could not tell

    Choose Quick for what is recommended, or Tailored for about eight questions: the kind of site, your brand, your languages, a color mode switch, and a short Luz section for your AGENTS.md.

  3. It shows you the plan

    Every package it will install, every file it will create, and the diff of every file it will change. Nothing is written until you say yes.

  4. It does it, then checks it

    It installs, writes, and runs luz-check on the result. If the install fails, it prints the steps that are left, so the project is never half done.

When you want toAdd
Take what is recommended, with no questions--yes
See the plan and the diffs, and write nothing--dry-run
Answer numbered questions, with no boxes and no spinners--accessible
Write the files, but install nothing--no-install
Turn colour off--no-color, or NO_COLOR=1

Run it again at any time: it never installs twice, and in a project that already has Luz it offers only what is missing. Every question has a flag, listed in Use Luz with an AI.

A preview.

@luz-ds/create is a proposal and is not published yet. Until it is, set Luz up by hand, below.

Or set it up by hand

Everything the setup does, you can do in three steps.

Choose a level

Luz is three packages that stack in one direction. Each needs the one below it and nothing above it, so you can stop at any level.

You wantInstallLoad, in order
The tokens only@luz-ds/tokensluz-tokens.css
Tokens and components@luz-ds/tokens @luz-ds/coreluz-tokens.css, luz.css
The page patterns toothe two above and @luz-ds/catalogthe two above, then one stylesheet per pattern

Install it

  1. Add the packages

    With npm, pnpm or Yarn. There is nothing else to install, because Luz has no dependencies of its own.

    No build step? Skip this and link the files from a CDN.

  2. Link the stylesheets

    Tokens first, then core. The order matters: core reads the tokens.

  3. Write HTML

    No class, no attribute. Text, controls and tables come out finished.

  4. Add a class when HTML runs out of words

    A link that should look like a button. A smaller size. A component with markup of its own. That is what classes are for, and they all start with luz-.

Or use a CDN

Two lines in the <head>, and nothing on your disk. Good for a prototype, a CodePen or a page with no build. The link names an exact version, never latest, and carries the integrity hash of the file. The docs write both for you.

Add the JavaScript, if you want it

Every component works without a script. The script adds the comforts: tabs that switch in place, a table that sorts, a toast that announces itself.

Already have a design?

Load luz.conditional.css instead and mark a region with data-luz. Luz stays inside it, and you migrate one region at a time.
