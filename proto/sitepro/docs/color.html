Color

Two layers of color. Primitives are the paint. Semantic tokens are the decisions, and the only ones a component is allowed to read.

A ramp of ten steps per family, from the lightest tint to the deepest shade. Never use one directly in a component: reach for the semantic token that points at it.

Semantic tokens

A semantic token names a job, not a color. Change what it points at and every component that reads it follows.

TokenPoints atUse it for
--luz-brand-primaryblue-70Links and text that acts.
--luz-brand-fillblue-60The fill of a primary button.
--luz-brand-fill-hoverblue-70The same fill, under the pointer.
--luz-brand-subtleblue-20A quiet wash behind something selected.
--luz-focus-ringblue-60The outline of the focused element.
--luz-input-borderpaper-70The edge of a text field.
--luz-color-successgreen-70It worked.
--luz-color-dangerred-60It did not, or it will destroy something.

Three modes

The same tokens, three sets of values. A component never asks which mode it is in. It reads the token and gets the right answer.
