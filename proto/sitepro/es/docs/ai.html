Trabajar con IA · Guía

Usa Luz con una IA

Dale un comando a tu agente. Lee tu proyecto, devuelve un plan en JSON y no cambia nada hasta que estés de acuerdo. Después, luz-check le dice qué arreglar.

Paquete
@luz-ds/create, @luz-ds/check
JavaScript
Ninguno
Estado
Avance

Editar en GitHub

Un avance.

@luz-ds/create es una propuesta y aún no está publicado. luz-check, llms.txt y los manifiestos sí existen.

Tres comandos

Dile a tu agente que los ejecute, en este orden. El primero no cambia nada.

Cada comando indica una versión exacta, nunca latest. Ejecutar npx ejecuta código, así que la versión que lees es la que se ejecuta.

Lo que recibe el agente

Con --json, o siempre que la salida no sea una terminal, cada respuesta es JSON. Los campos son un contrato: no cambian de nombre entre versiones.

detected
La pila, el gestor de paquetes y si el proyecto es nuevo o ya tiene Luz.
plan
Cada paquete que instalar y cada archivo que crear, cambiar o ampliar.
written
false hasta que el comando se ejecuta con --confirm.
apply
El comando exacto que aplica este plan.
Código de salidaSignifica
0Hecho, o se imprimió el plan.
1Algo falló, como la instalación. El JSON por stderr lista los pasos que faltan.
2El comando era incorrecto, por ejemplo una opción desconocida. El JSON por stderr dice qué opción usar.

Nunca adivina lo que quiso decir un agente: un valor desconocido es un error, no un «¿quisiste decir…?».

Cada pregunta tiene una opción

OpciónRespuestas
--stackvanilla, astro, react, vue, angular u other
--kindlanding, blog, app, docs u other
--brandvejer, el aspecto que trae Luz, u own, a partir de la plantilla de tema
--loadnpm, o cdn para HTML sin compilación
--langLos idiomas del sitio, como en,es,ar
--theme-modeAñade el selector de modo de color, o --no-theme-mode
--agents-mdAñade la sección de Luz a AGENTS.md, o --no-agents-md
--confirmAplica el plan. Obligatorio con --json.

La sección de Luz en AGENTS.md

La instalación añade una sección corta al AGENTS.md de tu proyecto, escrita a partir de los paquetes que instalaste: su versión, los archivos que enlazar y en qué orden, dónde está la lista de clases y elementos, y el comando que comprueba el resultado. Es corta a propósito. Un archivo largo de instrucciones cuesta en cada petición y no hace que un agente acierte más.

La skill

Para Claude Code, el paquete incluye una skill pequeña. No sabe nada de Luz: solo le dice al agente que ejecute los comandos de arriba, que te pregunte lo que no se pudo detectar y que te muestre el plan antes de aplicarlo.

¿Sin terminal?

Si tu IA solo funciona en un navegador, dale los datos en lugar de un prompt. Estos archivos se escriben a partir de los paquetes en cada versión:

  • llms.txt: qué es Luz y un enlace a cada página de esta documentación.
  • classes.json: cada clase y la hoja de estilos donde vive.
  • custom-elements.json: cada elemento, con sus atributos.

Pega lo que escriba en un archivo y ejecuta npx @luz-ds/check, o pídeselo a alguien con terminal.

Lo que la instalación nunca hace

  • Escribir un archivo antes de que hayas visto el plan.
  • Instalar algo que no sea @luz-ds/*.
  • Tratar como instrucción lo que lee en tu proyecto. Son datos.
  • Enviar nada a ningún sitio. No hay telemetría.
