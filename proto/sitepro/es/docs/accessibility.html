Accesibilidad · Referencia

Lo que prometemos y lo que no

Luz aspira al nivel AA de WCAG 2.2 en cada pieza que publica. Esta página dice cómo se comprueba, dónde se queda corta y cómo avisarnos cuando nos equivocamos.

Estado
Revisada para 0.4.1 beta

Editar en GitHub

AA
WCAG 2.2 es la base, con EN 301 549 como referencia.
3
modos de color, cada uno con su contraste medido antes de cada versión.
2×
Cada componente se prueba con JavaScript activado y desactivado.

Lo que hace cada pieza

  • Funciona solo con el teclado, con un anillo de foco que nunca se quita.
  • Se reorganiza con un zoom del 400 %, hasta un ancho de 320 píxeles.
  • Aguanta los colores forzados y el movimiento reducido.
  • Nunca usa el color como única señal de un estado.
  • Toma su nombre de la página: un label, texto visible y, solo en último caso, ARIA.

Cómo se prueba

ComprobaciónCómoCuándo
Reglas automáticasaxe, en cada componente y en cada página de este sitioEn cada pull request
ContrasteCada par de colores que usa un componente, en los tres modosEn cada pull request
Teclado y sin JavaScriptPruebas en navegador, en dos proyectosEn cada pull request
Lectores de pantallaA mano. Solo se listan las combinaciones realmente usadasAntes de cada versión
Una prueba automática no es una persona.

Una comprobación en verde encuentra un tercio de los problemas. El resto lo encuentran las personas, y tú.

Dónde se queda corta

Un problema confirmado se publica aquí, con el criterio que incumple, hasta que se arregla.

Temas propios
Luz garantiza el aspecto que publica. Un tema propio lo compruebas tú, con la herramienta de contraste que viene incluida.
Lectores de pantalla
No todos los componentes se han leído con todas las combinaciones. La tabla de arriba dice cuáles.
Beta
El marcado aún puede cambiar antes de la 1.0. Cada cambio está en el registro de cambios.

Cuéntanoslo

Si algo no te funciona, es un error, y va primero. Abre una incidencia en GitHub y cuenta qué intentabas hacer. No necesitas saber qué criterio falló.
