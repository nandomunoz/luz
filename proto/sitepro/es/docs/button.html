Botón

Lo único de la página que quieres que la gente haga. Un botón nativo, terminado, sin ninguna clase.

Código

Copia el marcado

Un <button> no necesita nada. Usa la clase cuando el elemento no sea un botón o cuando necesites una variante que HTML no puede expresar.

Variantes y opciones

ClaseAspectoPara qué usarla
luz-btnPrincipalLa acción principal. Una por vista.
luz-btn--secondarySecundarioTodo lo demás que sigue siendo una acción.
luz-btn--dangerEliminarUna acción que destruye algo.
luz-btn--smPequeñoFilas densas y barras de herramientas.
luz-btn--lgGrandeLa llamada a la acción de un hero.
luz-btn--blockAncho completoPantallas estrechas y formularios en una columna.

Cómo funciona

Luz distingue las variantes por su significado, no por la clase. Un botón que envía es principal. Uno que no envía es secundario. Lo dices con el atributo type que ya escribías.

Sin JavaScript

El botón no tiene script. Es igual con JavaScript activado o desactivado.

Teclado y ARIA

Tab
Mueve el foco al botón. El anillo de foco siempre se ve.
Enter Space
Lo activa. Un enlace con aspecto de botón responde solo a Enter, como todos los enlaces.
disabled
Saca el botón del orden de tabulación y baja su contraste. Evítalo en formularios. En una barra de herramientas, aria-disabled="true" lo mantiene enfocable.
aria-pressed
Para un interruptor. El estado pulsado tiene un borde además de un color.

Diseño

Cuándo usarlo

  • Para enviar un formulario o hacer algo en la página.
  • Para empezar una tarea: abrir un diálogo, añadir una fila, enviar un mensaje.

Cuándo no usarlo

  • Para ir a algún sitio. Eso es un enlace, aunque parezca un botón.
  • Para una segunda acción principal. Si todo es principal, nada lo es.
  • Desactivado para impedir el envío de un formulario. Déjalo activo y, al pulsarlo, di qué falta.

Qué hacer y qué no

Cómo escribir el contenido

Dos o tres palabras. Mayúscula solo al principio. Un verbo primero: «Guardar cambios», no «Cambios». Nunca «Haz clic aquí».
