Patrones para un sitio entero

Las 41 piezas que actúan para un sitio completo y la estructura de página de cuatro tipos de sitio. Una hoja de estilos cada una: enlaza solo las que uses.

Paquete
@luz-ds/catalog
JavaScript
Solo donde un patrón lo necesita

Editar en GitHub

Empieza por un tipo de sitio

Un patrón indica para qué tipos de sitio encaja mejor. Elige el tuyo y obtendrás la lista corta.

  • Página de aterrizaje
  • Blog o periódico
  • Aplicación web
  • Documentación

Estructura de página

  • Cabecera del sitioLa parte de arriba de cada página: el nombre, los enlaces, la acción.AterrizajeBlog
  • HeroUna frase, una acción, en lo alto de la página de inicio.Aterrizaje
  • Cabecera editorialEl nombre de una publicación, como lo compone un periódico.Blog
  • Barra de aplicaciónLa barra de una aplicación web, con sus herramientas.App
  • Estructura de docsBarra lateral, artículo y raíl de página. La estructura de esta página.Docs
  • Pie del sitioEl mapa del sitio, la licencia, la letra pequeña.AterrizajeBlog

Navegación

  • Barra de navegaciónLos enlaces del sitio, en una fila que se pliega en pantallas pequeñas.Todos
  • Barra lateralEnlaces agrupados con seguimiento del scroll. Un popover nativo en el móvil.DocsApp
  • PaginadorAnterior y siguiente, al final de una página.DocsBlog

Para todo el sitio

  • BuscarBusca en el sitio con un diálogo nativo. Un enlace normal sin JavaScript.Script
  • Consentimiento de cookiesHace una vez la pregunta de las cookies del sitio y recuerda la respuesta.Script
  • Selector de idiomaLos idiomas del sitio, como enlaces.Solo CSS
  • AnuncioAlgo que todo visitante debería saber.Solo CSS

Gráficas

Cada gráfica es una hoja de estilos sobre una lista, tabla o meter nativos que se quedan en la página. Quita el CSS y los datos siguen ahí.

  • Lista de barrasUna lista ordenada con una barra detrás de cada fila.App
  • Gráfica de columnasValores a lo largo del tiempo, dibujados a partir de una tabla.App
  • Mapa de calorUna cuadrícula de días, con un tono por valor.App
