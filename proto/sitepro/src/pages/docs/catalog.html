Start from a kind of site

A pattern says which kinds of site it fits best. Pick yours and you get the short list.

  • Landing page
  • Blog or newspaper
  • Web application
  • Documentation

Page structure

  • Site headerThe top of every page: the name, the links, the action.LandingBlog
  • HeroOne sentence, one action, at the top of the home page.Landing
  • MastheadThe name of a publication, as a newspaper sets it.Blog
  • App barThe bar of a web application, with its tools.App
  • Docs layoutSidebar, article and page rail. The layout of this page.Docs
  • Site footerThe map of the site, the licence, the small print.LandingBlog

Navigation

  • NavbarThe links of the site, in a row that folds on a small screen.All
  • SidebarGrouped links with a scroll spy. A native popover on a phone.DocsApp
  • PagerPrevious and next, at the end of a page.DocsBlog

Site-wide

  • SearchSearches the site in a native dialog. A plain link without JavaScript.Script
  • Cookie consentAsks the site's cookie question once, and remembers the answer.Script
  • Language switchThe languages of the site, as links.CSS only
  • AnnouncementOne thing every visitor should know.CSS only

Charts

Every chart is a stylesheet over a native list, table or meter that stays in the page. Turn the CSS off and the data is still there.

  • Bar listA ranked list with a bar behind each row.App
  • Column chartValues over time, drawn from a table.App
  • Heat mapA grid of days, a shade per value.App
