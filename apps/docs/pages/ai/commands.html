The commands

Type /luz in your assistant, with a subcommand or without. The word after it is the subcommand, and a word that is not in the table gets the table. The same names run in a terminal with luz-ai.

The conversations are real: each one is the text of a run of the skill that passed its checks, frozen as it was said, with the model and the date. They are English, whatever the language of this page, because that is what the assistant said. The output of the terminal is what the script prints when this site is built. How to install the skill is on the page about working with AI. The skill is tested only in Claude Code: the other assistants follow their own documentation. If one of them fails, tell us.

Other commands

One command for the terminal.

  • npx @luz-ds/ai init --target <assistant> installs the skill for claude, codex, gemini, cursor or agents-md. It runs only in a terminal, never in the chat, and it never overwrites a file without --force.
