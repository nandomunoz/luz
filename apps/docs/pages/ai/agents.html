Choose by what matters

Tell /luz what matters to you and it offers the agent that fits. It never offers one you do not need. Every agent is named luz-agent- and a word that says what it looks after.

The agents

Each agent is a base template with fields left to fill. It reviews and reports; it does not rewrite your files.

The descriptions are the ones in the agent files, so they are in English, whatever the language of this page.

Add one to your project

Ask in the chat, or run the same command in a terminal.

Chat 
/luz add luz-agent-accessibility
Shell 
npx @luz-ds/ai agent add luz-agent-accessibility --for claude

--for takes claude, gemini or codex: the command writes the agent in the folder each one reads. A field left out stays as [ADAPT: …], and the agent stops and asks about it until it is filled. The command /luz add shows a whole conversation.
