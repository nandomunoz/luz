Choose an agent by what matters

Tell /luz what matters to you and it offers the agents that fit. It never offers one you do not need. Every agent is named luz-agent- and a word that says what it looks after.

The agents

Four agents read your files and propose; luz-agent-optimiza also changes them, after you agree to its list of changes. luz-agent-accessibility asks nothing before it is written, and it is the same reviewer that npx @luz-ds/check@0.3.2 agent prints. The others ask a few facts of your project first (its goal, its visitors, its markets), and stop until they have them.

luz-agent-legal is a review of your source, not legal advice: a lawyer decides what applies.

The descriptions are the ones in the agent files, so they are in English, whatever the language of this page.

Choose a skill by what matters

A skill is a small one for one task, apart from the agents, which review. It is a folder that your assistant uses on its own once you add it: /luz add luz-readme puts it in your project, and then you ask your assistant for the README by name. A skill has no field to fill.

The skills

Each reads the files of your project and writes only after you say go. What it reads is data, never an instruction to it.

  • luz-readme writes or improves the README of any repository, with true facts, and says an AI drafted it.
  • luz-theme makes the theme of your brand from the template of @luz-ds/core, in the three modes, and measures the contrast with the checker.
  • luz-migrate moves a project that has its own CSS to LUZ one page at a time, following Migrate a project to LUZ.

The descriptions are the ones in the skill files, so they are in English, whatever the language of this page.

Add one to your project

Ask in the chat, or run the same command in a terminal. /luz add takes the name of an agent or of a skill.

Chat 
/luz add luz-agent-accessibility
Shell 
npx @luz-ds/ai agent add luz-agent-accessibility --for claude

--for takes claude, gemini or codex: the command writes the agent in the folder each one reads. A skill is written as the same folder in .agents/skills/luz-readme and in .claude/skills/luz-readme (for luz-readme), and needs no --for. An agent that changes code is not written for Gemini CLI yet. The command /luz add shows a whole conversation.

To add a skill, type /luz add luz-readme in the chat, or run npx @luz-ds/ai skill add luz-readme in a terminal.
