Choose by what matters

Tell /luz what matters to you and it offers the agents that fit. It never offers one you do not need. Every agent is named luz-agent- and a word that says what it looks after.

The agents

Four agents read your files and propose; luz-agent-optimiza also changes them, after you agree to its list of changes. luz-agent-accessibility asks nothing before it is written, and it is the same reviewer that npx @luz-ds/check agent prints. The others ask a few facts of your project first (its goal, its visitors, its markets), and stop until they have them.

luz-agent-legal is a review of your source, not legal advice: a lawyer decides what applies.

The descriptions are the ones in the agent files, so they are in English, whatever the language of this page.

Add one to your project

Ask in the chat, or run the same command in a terminal.

Chat 
/luz add luz-agent-accessibility
Shell 
npx @luz-ds/ai agent add luz-agent-accessibility --for claude

--for takes claude, gemini or codex: the command writes the agent in the folder each one reads. An agent that changes code is not written for Gemini CLI yet. The command /luz add shows a whole conversation.
