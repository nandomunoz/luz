Elige por lo que te importa

Dile a /luz lo que te importa y te ofrece el agente que encaja, el recomendado primero. Nunca ofrece uno que no necesitas: un sitio sin función de IA no necesita el auditor de IA.

Los agentes

Cada agente es una plantilla base con campos por rellenar. Revisa e informa; no reescribe tus archivos.

Las descripciones son las de los archivos de los agentes, así que están en inglés, sea cual sea el idioma de esta página.

Las skills

Una skill es un comando propio, con sus referencias, que escribes en tu asistente como /luz.

Añade uno a tu proyecto

Pídelo en el chat o ejecuta el mismo comando en una terminal.

Chat 
/luz add luz-seo-geo-specialist
Shell 
npx @luz-ds/ai agent add luz-seo-geo-specialist --for claude

--for admite claude, gemini o codex: el comando escribe el agente en la carpeta que lee cada uno. Un campo que dejes sin rellenar queda como [ADAPT: …], y el agente se detiene y te pregunta por él hasta que se rellena. El comando /luz add muestra una conversación entera.
