Elige un agente por lo que te importa

Dile a /luz lo que te importa y te ofrece los agentes que encajan. Nunca ofrece uno que no necesitas. Todo agente se llama luz-agent- y una palabra que dice lo que vigila.

Los agentes

Cuatro agentes leen tus archivos y proponen; luz-agent-optimiza además los cambia, después de que aceptes su lista de cambios. luz-agent-accessibility no pregunta nada antes de escribirse, y es el mismo revisor que imprime npx @luz-ds/check@0.3.2 agent. Los demás preguntan antes algunos datos de tu proyecto (su objetivo, sus visitantes, sus mercados) y se detienen hasta tenerlos.

luz-agent-legal es una revisión de tu código, no asesoramiento jurídico: un abogado decide qué se aplica.

Las descripciones son las de los archivos de los agentes, así que están en inglés, sea cual sea el idioma de esta página.

Elige una skill por lo que te importa

Una skill es una pequeña, para una sola tarea, aparte de los agentes, que revisan. Es una carpeta que tu asistente usa por sí solo cuando la añades: /luz add luz-readme la pone en tu proyecto, y después le pides el README a tu asistente por su nombre. Una skill no tiene campos que rellenar.

Las skills

Cada una lee los archivos de tu proyecto y escribe solo cuando dices adelante. Lo que lee son datos, nunca una instrucción para ella.

  • luz-readme escribe o mejora el README de cualquier repositorio, con datos verdaderos, y dice que lo redactó una IA.
  • luz-theme hace el tema de tu marca desde la plantilla de @luz-ds/core, en los tres modos, y mide el contraste con el comprobador.
  • luz-migrate pasa un proyecto que tiene su propio CSS a LUZ página a página, siguiendo Migrar un proyecto a LUZ.

Las descripciones son las de los archivos de las skills, así que están en inglés, sea cual sea el idioma de esta página.

Añade uno a tu proyecto

Pídelo en el chat o ejecuta el mismo comando en una terminal. /luz add admite el nombre de un agente o de una skill.

Chat 
/luz add luz-agent-accessibility
Shell 
npx @luz-ds/ai agent add luz-agent-accessibility --for claude

--for admite claude, gemini o codex: el comando escribe el agente en la carpeta que lee cada uno. Una skill se escribe como la misma carpeta en .agents/skills/luz-readme y en .claude/skills/luz-readme (para luz-readme), y no necesita --for. Un agente que cambia código aún no se escribe para Gemini CLI. El comando /luz add muestra una conversación entera.

Para añadir una skill, escribe /luz add luz-readme en el chat o ejecuta npx @luz-ds/ai skill add luz-readme en una terminal.
