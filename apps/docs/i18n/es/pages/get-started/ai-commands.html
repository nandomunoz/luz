Los comandos

Escribe /luz en tu asistente, con un subcomando o sin él. La palabra que sigue es el subcomando, y una palabra que no está en la tabla recibe la tabla. Los mismos nombres se ejecutan en una terminal con luz-ai.

Las conversaciones son reales: cada una es el texto de una ejecución de la skill que pasó sus comprobaciones, congelado tal como se dijo, con el modelo y la fecha. Están en inglés, sea cual sea el idioma de esta página, porque es lo que dijo el asistente. La salida de la terminal es lo que imprime el script cuando se construye este sitio. Cómo instalar la skill está en la página sobre trabajar con IA.

Otros comandos

Dos skills propias y un comando para la terminal.

  • /luz-readme redacta o audita el README de un proyecto y le quita las señales de escritura automática. Es una skill propia: luz-ai skill add luz-readme la añade.
  • /luz-landing planifica, construye o revisa una landing, sección a sección, con su SEO y GEO. luz-ai skill add luz-landing la añade.
  • npx @luz-ds/ai init --target <assistant> instala la skill para claude, codex, gemini, cursor o agents-md. Solo se ejecuta en una terminal, nunca en el chat, y nunca sobrescribe un archivo sin --force.
