# Anatomy of a landing with an integrated service

For digital products, web tools, calculators, generators and any interactive service embedded in the page.

The priority is that the visitor tries the product at once, with the least friction. Every other section exists to remove what stops that first use, or to convert the visitor who has already done it.

Limits, counters, privacy statements and prices are the real ones or are left out. See the principles in `SKILL.md`.

## 1. Minimal header

It does not compete with the tool below it.

- Logo on the left.
- Navigation to tools, formats or use cases.
- Link to pricing (if freemium) and to the API documentation.
- "Sign in" and "Sign up", always optional for the first use.

## 2. Hero with the service

The product lives here. The visitor understands what it does and can use it in under five seconds, without scrolling.

- Functional headline: what the service does and which problem it solves, in one sentence.
- Subheadline: how easy, fast or free the first use is.
- One trust metric: volume processed, rating or client logos.
- The widget, as the lead:
  - An interface ready to use: drop zone, text or URL field, option selector, live configurator.
  - Limits in sight next to the button: maximum size, free uses per day, accepted formats.
  - A button with the verb of the action: "Convert now", "Generate", "Analyze", "Calculate".

## 3. Privacy, security and speed bar

The main brake when uploading a file or pasting data is distrust.

- What happens to the data: "your files are deleted after X hours", "everything is processed in your browser", "encrypted connection". Only what is true.
- Zero friction: it runs in the browser, nothing to install.

## 4. Operational advantages

A grid of three to six blocks with an icon. Technical and practical advantages, not emotional ones:

- Speed and where the processing happens.
- Advanced settings: control over quality, parameters or output format.
- Works the same on mobile, tablet and desktop.
- Quality of the result: the technology behind it.

## 5. How it works

1. **Input.** Upload the file, paste the link or type the data.
2. **Process.** Choose the options and the system works.
3. **Result.** Download, copy or share.

## 6. Directory of use cases and related tools

Replaces the product categories. It serves the visitor and the search engines.

- Popular variants and formats: "X to Y", "Templates for", "Advanced mode".
- Other tools of the same platform.

## 7. Social proof and technical backing

- Usage counter: operations done or active users.
- Short reviews about time saved, accuracy and ease of use.
- Logos of media or companies that use it.

## 8. Pro plans and API

- Free against Pro: limits, batches, speed, no ads.
- A block for developers with a link to the API documentation.

## 9. Technical FAQ

Accordion with the operational doubts:

- Is it really free, and what are the limits?
- What happens to my data and my files?
- Which formats, languages or parameters are supported?
- Do I need an account?

## 10. Close and footer

- A CTA that scrolls smoothly back to the widget at the top.
- Footer in columns: tools and formats, resources (blog, guides, service status, API), company and legal, language selector and social profiles.
